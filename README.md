# Техническое введение

Portmaster — это пакет для обеспечения приватности на вашем рабочем столе Windows и Linux.

### Базовая технология

- Portmaster встраивается в сетевой стек, используя nfqueue в Linux и драйвер ядра (WFP) в Windows.
- Пакеты перехватываются на уровне необработанных пакетов — каждый пакет виден и может быть остановлен.
- Принадлежность соединений определяется с помощью eBPF и `/proc` в Linux, а также драйвера ядра и IP Helper API (`iphlpapi.dll`) в Windows.
- Большинство настроек можно задать для каждого приложения; сопоставление приложений возможно разными способами.
- Поддержка особых процессов со странными или скрытыми путями/субъектами:
  - Поддержка Snap, AppImage и скриптов в Linux
  - Поддержка приложений Windows Store и системных служб svchost.exe в Windows
- Всё работает на 100% локально на вашем устройстве. (кроме SPN, разумеется)
  - Обновления полностью подписываются и загружаются автоматически.
  - Данные аналитики (списки блокировок, geoip) загружаются и применяются автоматически.
- Основная служба Portmaster работает как системная служба, элементы интерфейса (приложение, уведомитель) работают в контексте пользователя.
- Основной интерфейс всё ещё использует Electron как обёртку :/ — но в будущем это изменится. Вы также можете открыть интерфейс в браузере.

### Возможность: Безопасный DNS

- Portmaster перехватывает «заблудшие» DNS-запросы и перенаправляет их себе для бесшовной интеграции.
- DNS-запросы разрешаются стандартными или настроенными резолверами DoT/DoH.
- Полная поддержка split horizon и проверки горизонта для защиты от атак повторного связывания (DNS rebinding).

### Возможность: Фильтр приватности

- Определяйте разрешённые сетевые области: localhost, LAN, интернет, P2P, входящие.
- Простые правила на основе интернет-сущностей: домен, IP, страна и другое.
- Списки фильтров блокируют распространённые домены вредоносного ПО, рекламы, трекеров и т. д.

### Возможность: История сети ($)

- Записывайте соединения и их подробности в локальную базу данных и ищите по ним позже
- Автоматически удаляйте старую историю или удаляйте по запросу

### Возможность: Видимость пропускной способности ($)

- Отслеживайте использование пропускной способности по каждому соединению и приложению

### Возможность: SPN — Safing Privacy Network ($$)

- Приватная сеть, предназначенная для сценариев «между» VPN и Tor.
- Использует луковое шифрование через несколько узлов, как Tor.
- Маршруты выбираются так, чтобы покрывать наибольшее расстояние внутри сети, повышая приватность.
- Выходные узлы выбираются рядом с сервером назначения. Во многих случаях это автоматически обходит географические блокировки.
- Исключайте приложения и домены/сущности из использования SPN.
- Изменяйте алгоритм маршрутизации и фокус для каждого приложения.
- Узлы размещаются Safing (компанией, стоящей за Portmaster) и сообществом.
- Скорость вполне достойная (>100 Мбит/с).
- Дополнительные материалы: [Белая книга SPN](https://safing.io/files/whitepaper/Gate17.pdf)
